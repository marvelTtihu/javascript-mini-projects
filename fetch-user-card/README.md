# Fetch user card

A project to fetch and display user data via a mock API.

### Concepts used
- DOM Manipulation `getElementById`, `innerHTML`
- Async/await
- Arrow function
- Fetch API
- Error handling `try/catch`

### How to run
1. Clone this repo
```bash
   git clone https://github.com/marvelTtihu/javascript-mini-projects.git
```
2. Open the `fetch-user-card/` folder
3. Open `index.html` in your browser — no server needed

### File
- `fetch-user-card/index.html` — main page
- `fetch-user-card/script.js` — fetch logic
- `fetch-user-card/style.css` — styling

### API used
[JSONPlaceholder](https://jsonplaceholder.typicode.com/) — `GET /users/1`
