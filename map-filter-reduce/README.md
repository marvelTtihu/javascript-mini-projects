# Product data management

a simple javascript project to filter and calculate product inventory data using ES6 

### Concepts used
- Array Methods `.filter() .map() .reduce()`
- Arrow Function
- Array of objects

### How to run
1. Copy the code into your JS file or browser console.
2. Run `console.log({ nameProduct, electronics, total })` to see the result

### File
- `map-filter-reduce/index.js`
