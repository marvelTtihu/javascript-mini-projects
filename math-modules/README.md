# Math Module learning

This is a mini learning module using mathematics.

### Concepts Used
- DOM Manipulation `querySelector`
- Modules `Import/export`
- Event handling `addEventListener('click')`
- Arithmetics 

### How to run
1. Clone this repo
```bash
   git clone https://github.com/marvelTtihu/javascript-mini-projects.git
```
2. Open the `math-modules/` folder
3. Open `index.html` in your browser — no server needed

### How to Change Numbers
Hardcoded calculated numbers in `app.js`. To change, open `app.js` and change the value in each function call:

```javascript
sum(5, 5) // replace 5 and 5 as desired
subtract(5, 5)
multiply(5, 5)
```
### File
- `math-modules/index.html` — main page
- `math-modules/app.js` — module logic
- `math-modules/style.css` — styling
- `math-modules/utils/math.js` - Export module logic
